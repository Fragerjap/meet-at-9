# Meet-at-9
Meeting organizer app (raw AS IS for self-host)

Greetings! One day I needed to coordinate day/time for a meeting for several users with zero hussle.
I wanted something even more simple than Google Sheets and with no authorization whatsoever.
That's when I asked Replit to create it for me, and the result was so satisfying, I wished to share it:
